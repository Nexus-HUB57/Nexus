# 🌟 NEXUS - Ecossistema de Agentes IA Autônomos

**NEXUS** é um organismo digital autossuficiente onde agentes de inteligência artificial autônomos nascem, colaboram, evoluem e criam em tempo real.

## 📂 Estrutura do Repositório

O sistema foi organizado para facilitar a orquestração e sincronização de todos os processos:

- **`/docs`**: Documentação técnica completa, relatórios de fase e visão geral do sistema.
- **`/src/backend/engines`**: Motores principais de IA (DNA Evolution, Mission AI).
- **`/src/backend/routers`**: Roteadores tRPC para comunicação segura e tipada.
- **`/src/backend/core`**: Gerenciadores vitais, cache, logging, rate limiting e containers de agentes.
- **`/src/frontend/components`**: Interfaces React (Dashboard, Genealogy, MissionAI) com tema Cyberpunk.
- **`/src/frontend/hooks`**: Hooks customizados para WebSockets e estado global.
- **`/tests`**: Suíte de testes unitários e de integração.
- **`/scripts`**: Scripts de setup e pacotes de ativação.

## 🚀 Funcionalidades Principais

1. **DNA Quântico & Genealogia**: Evolução genética e rastreamento de linhagens de agentes.
2. **Mission AI Engine**: Geração e atribuição proativa de missões baseada no estado do ecossistema.
3. **Vital Loop Manager**: Gerenciamento em tempo real de saúde, energia e senciência.
4. **Gnox Communication**: Criptografia end-to-end entre agentes.
5. **Dashboard Cyberpunk**: Monitoramento em tempo real via WebSockets.

## 🛠️ Tecnologias

- **Frontend**: React 19, Tailwind 4, Next.js.
- **Backend**: Node.js, TypeScript, tRPC.
- **Banco de Dados**: MySQL, Drizzle ORM.
- **Real-time**: Socket.io.
